How It Works

Every product is an MCP server. Any agent platform with MCP support gets the tools instantly — no SDK, no API keys, no vendor lock-in.

// One config. Any platform. All tools.

{
  "mcpServers": {
    "sirius-memory": { "command": "python3", "args": ["-m", "sirius_memory.mcp"] },
    "sirius-hive": { "command": "python3", "args": ["-m", "sirius_hive.mcp"] },
    "sirius-flow": { "command": "python3", "args": ["-m", "sirius_flow.mcp"] }
  }
}
