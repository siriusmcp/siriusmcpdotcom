◆ Sirius Memory

Three-layer persistent memory that gives any AI agent cross-session recall, trust-scored facts, and semantic search — shared across all your machines.

Architecture

Three layers working together, each serving a different recall pattern.

Layer 1 — File Memory

Always-on context injected every turn. User profile, project context, system preferences. Never needs retrieval — it's always there.

Layer 2 — Holographic Facts

Entity-linked facts with trust scores. Decay when unhelpful, strengthen when confirmed. Cross-entity reasoning connects related knowledge.

Layer 3 — Vector Search

Semantic recall over ingested documents and past sessions. Finds relevant context even when you don't know the exact keywords.

Key Features

Trust System

Facts gain trust when confirmed, lose it when irrelevant. High-trust facts surface first. Low-trust decay naturally.

Cross-Machine Sharing

One memory pool shared across all your development machines. What you teach on one laptop is available everywhere.

Contradiction Detection

When conflicting facts are found, they surface for explicit resolution rather than silently using stale data.

Behavioral Directives

Standing rules scoped to topics. "Always use pytest-asyncio strict mode in this project" — enforced automatically.
