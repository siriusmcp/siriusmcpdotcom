◆ Sirius Hive

Real-time coordination bus for concurrent agents. Conventions, shared scratchpad, decisions, conflict resolution — session-scoped, no polling, zero setup.

How It Works

Orchestrator front-loads conventions, agents join and follow. Reduces multi-agent coordination from distributed consensus to read-the-spec-and-follow.

Conventions

Immutable rules validated at check time. Set naming styles, error shapes, API patterns — agents validate before committing.

Scratchpad

Shared key-value store with namespace protection. Agents publish interfaces, read each other's output, append to shared lists.

Decisions

Audit trail of implementation choices. Every agent records what they decided and why — prevents re-litigation.

Conflicts

Structured issue tracking within a session. Agents flag inconsistencies; orchestrator resolves. Nothing gets silently swallowed.

Convention Validation

The killer feature. Agents check proposed names against established patterns before committing — violations get caught with suggested fixes.

// Set convention
hive_convention_set(category="casing", rule="snake_case for all identifiers", immutable=true)

// Agent checks before naming
hive_convention_check(category="casing", proposed="getUserProfile")

// Response:
{ status: "conflict", suggested_fix: "get_user_profile" }
